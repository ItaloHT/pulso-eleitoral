# Pulso eleitoral

Site de acompanhamento de pesquisas eleitorais. Código estático, sem dependências de build.

A publicação usa GitHub Pages. Em Settings → Pages, selecione GitHub Actions como fonte.

Dados em `data.json`. Preserve fontes, histórico e a identificação de resultados experimentais. A média histórica ainda depende da recuperação e validação dos pesos individuais.
